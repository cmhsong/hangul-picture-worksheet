# 한글 그림 학습지

낱말·짧은 문장·긴 문장을 넣으면 여자 또는 남자 목소리로 읽어 주고, 알맞은 그림을 붙여 A4 학습지로 만들어 주는 웹 도구입니다. 설치 없이 `index.html`만 열면 됩니다.

## 할 수 있는 일

- **글자 넣기** — 한 줄에 하나씩 적으면 낱말 / 짧은 문장 / 긴 문장으로 알아서 나눕니다. 낱말·문장과 그림은 언제든 더 넣을 수 있습니다.
- **읽어 주기** — 여자·남자 목소리, 빠르기 조절, 전체 듣기.
- **그림** — 구글 Noto 그림, 도트 그림(칸 수 조절), 위키백과·위키미디어 공용 사진, 내 그림 올리기·붙여넣기(Ctrl+V), 구글 무료 이미지 검색 바로가기.
- **문장 그림** — 문장은 낱말마다 작은 그림을 여러 개(4개까지) 나란히 넣을 수 있습니다.
- **글씨·소리·화면** — 글씨 크기, 긴 문장 자동 줄바꿈, 목소리 크기와 빠르기, 미리 보기 화면 크기를 조절할 수 있습니다.
- **학습지 종류** — 그림 카드, 따라 쓰기(네모 칸), 선 잇기.
- **고치기** — 글자·그림·순서·제목·안내 문구·글씨체·카드 수.
- **인쇄** — A4 세로, 여러 쪽 자동 나눔. 인쇄 창에서 "PDF로 저장"을 고르면 PDF가 됩니다.
- **나누기** — 학습지 내용이 담긴 주소와 QR. 받은 사람은 그림을 눌러 소리로 들을 수 있습니다.

## 알아 둘 점

- 목소리는 브라우저에 들어 있는 한국어 목소리를 씁니다. 원하는 성별의 목소리가 기기에 없으면 음높이를 바꿔 읽습니다. 엣지(Edge)에는 여자·남자 목소리가 모두 있습니다.
- 그림 찾기와 사진은 인터넷 연결이 필요합니다.
- 사진은 저작권 표시 조건(CC BY-SA 등)이 있을 수 있으니, 널리 배포할 때는 위키미디어 공용에서 출처를 확인하세요.
- 내 컴퓨터에서 올린 그림은 공유 주소에 담기지 않습니다. "파일로 저장"을 쓰면 함께 보관됩니다.
